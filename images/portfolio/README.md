# Portfolio image categories

Add your images to this folder, then replace a matching portfolio placeholder in `index.html` with an image tag.

Suggested filenames:

- `corporate-01.jpg` — corporate businesses, law firms, security, manufacturing, pharmacies
- `property-01.jpg` — real estate, venues, hotels, lodges, private properties
- `retail-01.jpg` — clothing, products, beauty, malls, furniture, hardware, car dealerships
- `events-01.jpg` — weddings, launches, conferences, modelling hosts
- `schools-01.jpg` — schools, campus life, graduations, community events
- `campaigns-01.jpg` — brand campaigns, promotions and social media content

For example, replace a placeholder with:

```html
<img src="images/portfolio/corporate-01.jpg" alt="Corporate business photography">
```
